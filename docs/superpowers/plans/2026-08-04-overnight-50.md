## READ THIS BEFORE TASK 1

### Hard constraints. Breaking one of these is worse than not finishing.

- **Never run `npm run build`. Never deploy. Never flip a feature flag.** Not `NEXT_PUBLIC_SPINE_REFORM_*`, not any other.
- **Never post to social media, send email, or submit anything to a third party.** Designing a social icon is in scope; creating an account is not.
- **Never fabricate a figure.** If a number is not in the data, the page states its absence. A page is always complete; its shape never varies by place.
- **Never rename a URL slug.** Add new routes; never rename existing ones. SEO equity rides on them.
- **Never `git checkout -- <file>`.** Use `git stash` if you must set work aside.
- **No em dashes** anywhere a reader could see, including data files you author. Commas, colons, semicolons, periods, parentheses.
- **No source-agency names** in user-facing copy. No "powered by" strip.
- **Banned vocabulary:** "turnover", "covers", "pp", "percentage points", "net margin".
- **No first person.** No "we", "us", "our", "I". Not in FAQ answers either.
- **No placeholder data in `data/`.** Placeholder fixtures live in `fixtures/`.
- **The founder designs; this loop ports and proposes.** New visual ideas are review artifacts under `design/loop4/reviews/`, never a change to a live page.

### The machine is memory-constrained. Verify accordingly.

The dev server has been killed repeatedly by memory pressure when Next dev and a second Chromium run together. `VirtualAlloc failed`, cygheap errors, and tsc OOM have all been seen.

**Verification order, cheapest first:**

1. `NODE_OPTIONS=--max-old-space-size=4096 npx tsc --noEmit` , always.
2. `npm run prebuild` , if it crashes with a spawn or alloc error, use `npm run prebuild:serial`. A crash is not a gate failure; re-run before concluding anything.
3. **Read the rendered page as prose.** This is the highest-yield check in the project: it has found nine defects that TypeScript and 58 gates could not see. Recipe:

```bash
cd /e/atlas/website
curl -s -m 600 http://localhost:3210/dev/PAGE -o /tmp/p.html
node -e '
const fs=require("fs");let h=fs.readFileSync(process.argv[1],"utf8");
h=h.replace(/<script[\s\S]*?<\/script>/g,"").replace(/<style[\s\S]*?<\/style>/g,"");
const t=h.replace(/<[^>]+>/g," ").replace(/&[a-z]+;/g," ").replace(/\s+/g," ").trim();
console.log(t.slice(0,2500));
' /tmp/p.html
```

Read it as a human would. Words fused together ("Londonmeasured16,765") mean a layout defect. Internal notes, years, or agency names mean unpublishable data reached a page.

4. Screenshots are **best effort**. Start the server with the `preview_start` tool (never `npm run dev` in Bash), warm one route at a time with `curl -m 600`, and if Playwright cannot hold a connection, say so in the journal and move on. **Do not spend more than 10 minutes per task fighting the dev server.**

### Design rules already learned. Do not rediscover these.

- **`.row` outside `.statblock` is completely unstyled.** Every rule is scoped `.statblock .row`. A run of rows belongs in `<div className="panel pad rise"><div className="statblock">`, **both classes on one element**, because `.panel.pad > .statblock` is what strips the inner border. `panel` and `pad` on nested divs does not match.
- **The value slot `.v` is a 78px figure column.** The figure goes there; the qualifier goes in `.nm > .s`. Longer strings clip silently, mid-word.
- **Resolve links, never assemble them.** `countryPageTarget()` for countries, `industryToSlug()` for trades, `geoPageTarget()` for places. Hand-built paths 404: Greece is stored as `GR`, so every `/el` link was dead.
- **No eyebrow above a heading.** A crumb naming the subject ("Restaurants, London") is a breadcrumb and is fine. A crumb labelling the section below it is an eyebrow and is banned.
- **Radius tokens only:** `--r-lg` 10, `--r-md` 8, `--r-sm` 6, `--r-xs` 4. Pills stay pills only on small controls.
- **Terracotta marks the answer once per section.** Fifty accents is no focal point.
- **Icons are drawn, never unicode.** `@phosphor-icons/react/dist/ssr` or `GlyphIcon`. 18px for a section head, 13px inline.
- **Every page carries `<Place />`** inside a `position: relative` `.av2`.
- **Data fields are not automatically publishable.** `industry_margins.json` notes contained internal audit language, an em dash, and a named source agency. Filter before printing.
