# Visual Direction (professional grade) + SEO/AEO , ratified 2026-06-21

Founder 40-question interview (35 visual + 5 SEO/AEO). Extends the Execution Constitution. These are binding direction decisions for the whole site.

## A. Originality & signature
- **Originality dial: distinctive but usable.** Ownable and memorable, every pattern still familiar enough to use without thinking.
- **The signature = the cartographic system** (topographic contour + custom brand maps). This is the ownable bet, tied to "Atlas".
- **Contour lives as quiet system accents only**: section dividers, loading shimmer, favicon/glyph, OG share cards. NOT in heroes, never loud.
- **Charts have a tight house style** with recognizable, ownable details (terracotta accent logic, label style, mono numbers) so any Atlas chart is identifiable out of context.

## B. Imagery strategy (solves the "AirPods" failure)
- **Curated, verified library**: one human-checked, correctly-tagged image per place. NO live auto-pick from stock APIs, ever.
- **Fallback when no photo exists: a branded cartographic/contour card.** Always available, never wrong, on-brand.
- **Mode: hybrid** , real photography where curated (flagship pages), maps/data-art for the long tail.
- **Licensing: free-license stock now** (Unsplash/Pexels), curated + verified; paid/commissioned only for the highest-traffic pages later.
- **Art direction**: a subtle unified grade (slight desaturation, cool, consistent) so all sources feel like one brand; **places & objects, avoid people** (no cheesy stock); **data-dominant** (images are accents, charts are the substance); mood **calm, premium, real**.

## C. Image choice per page type
- **Country hero**: skyline of the primary business city; cartographic card as fallback.
- **City hero**: skyline + the custom district map as the showpiece nearby.
- **Cell hero**: the trade-in-that-place photo where curated, else the interactive calculator leads.
- **Home hero**: the cartographic world (map/contour) + a prominent command-search.
- **Industry (GLOBAL) page**: abstract data-art of the trade's economics, no single-place photo.
- **Neighbourhood page**: street-level scene + a micro-map of the area.

## D. The cartographic asset system
- **Maps: minimal, abstract, brand-toned** (greyscale + terracotta, river/coast + markers).
- **Interactive where it adds value** (city district maps: hover/click for data); **static brand images** on country/home.
- **Contours derived from real topographic/elevation geometry**, used abstractly , one system generates endless on-brand variation.
- **Tooling: vector tiles styled to the brand (MapLibre + open data)** so every place renders automatically; no per-place hand-work.

## E. The asset kit
- **Icons**: one restrained open library (Lucide), tuned to brand, used sparingly + functionally only.
- **Flags**: clean flag images with a subtle unified frame (rounded, hairline border).
- **Share / OG cards**: auto-generated per page , headline stat + place name + contour texture. The shareability + AEO-citation engine.
- **Loading / empty states**: contour-based shimmer + branded "not enough data yet" states.

## F. The premium-feel layer
- **Motion: subtle, functional, fast** (hover feedback, state changes, the working calculators). No decorative scroll animation.
- **Depth: pure flat hairline cards**, with only a whisper of elevation on hover. No default shadows.
- **One elevated showpiece per page type** (country radar, city district map, cell calculator, home world view) , the screenshot moment.
- **Signature "alive" feel = crisp hover + the working make-it-yours calculators.** That tactile play-with-the-numbers is the brand verb.

## G. Consistency, density, sharing
- **Consistency at scale**: two-layer tokens + a locked component kit + automated visual/QC checks in CI. Nothing off-brand ships.
- **Data density: MAXIMAL on every page** (founder choice). NOTE: this raises thin/duplicate-content risk at the long tail , mitigated by the SEO uniqueness gate (H).
- **Chart embeds + PNG/share export, branded** (with attribution + backlink). A primary backlink/citation channel.
- **Trust layer**: a quiet held/modeled confidence tag + an "as of" date per section. Trust + freshness signal + honesty.

## H. Compare experience
- **Side-by-side cards running the identical section set in parallel**, so differences pop. Reuses the kit; highly shareable.

## I. SEO / AEO (life-or-death , the 5)
1. **Architecture: hub-and-spoke + dense contextual internal linking.** Country -> city -> cell -> neighbourhood, every page linking up/down/across (the low-repetition model already does this). Builds topical authority and spreads link equity.
2. **Indexing gate (critical given MAXIMAL density):** a page is indexable ONLY once it clears a uniqueness/data-depth threshold (enough held/modeled values, genuinely distinct from siblings). Thin pages stay `noindex` until filled. Protects the domain from a programmatic-thin-content penalty.
3. **Structured data + AEO:** rich schema.org (`Dataset` / `Place` / `QAPage`), **answer-first content** (the question, then the number), citable stats with as-of dates, plus the auto OG cards. This is how Atlas gets cited by answer engines and wins rich results.
4. **Technical foundation:** static pre-render (current stack) + top Core Web Vitals + `hreflang` for global reach. Fast + crawlable + international is the ranking/AEO floor.
5. **Authority / E-E-A-T:** make the DATA the link magnet , citable stats + branded embeds + a public methodology page + a named editorial voice (authorship). Compounding, organic, durable; the right engine for a new data domain.
