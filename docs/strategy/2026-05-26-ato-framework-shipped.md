# ATO benchmark framework: shipped state

**Date shipped:** 2026-05-26
**Status:** Live in production. All 8 phases complete.
**Parent docs:**
- [Research](./2026-05-26-ato-benchmark-framework-research.md)
- [Execution plan](./2026-05-26-ato-framework-execution-plan.md)

This is the closing summary of the ATO framework adoption. Eight
phases shipped sequentially, each behind a clean prebuild + commit +
push to main. The prebuild chain grew from 14 to 18 gates.

## What is live now

1. **Key-benchmark designation per sector.** Every cell page opens
   with a `KeyBenchmarkBanner` calling out the single ratio that
   matters most for that industry. The picker rule plus per-sector
   rationale ship in `data/finance/key_benchmark_assignments_v1.json`.

2. **Motor vehicle as a real cost line.** Added to the cost stack
   type, the AnnualCostStack renderer, and the bulk SQL generator.
   Trades and transport sectors get a meaningful share; office-based
   industries self-suppress the row.

3. **Comparative voice.** The KeyBenchmarkBanner now opens with an
   imperative sentence ("Watch your COGS. Typical cost of sales for
   this activity sits at X% to Y%...") generated by the new
   `comparative_narratives.ts` module. A warn-only gate
   `verify_comparative_voice` catches future regressions to passive
   "Typical operators report..." copy.

4. **20 sub-industry splits.** Taxonomy expanded from 223 to 243
   industries at the ATO A-Z resolution. Bricklaying is its own
   entry. Cake shops are not bakeries. Cement rendering is not
   construction. Each new sub-industry inherits cost shape from its
   parent until primary data lands.

5. **Turnover-band axis.** Every cell now carries a derived
   `turnover_band` (small / medium / large / unknown) computed from
   revenue + sector thresholds. Surfaced as a chip on the
   KeyBenchmarkBanner. Phase 6b will expose a switcher between
   employee-band and turnover-band navigation once per-sector
   thresholds are fully populated.

6. **`/check` comparator tool.** New route where an operator types
   their numbers, picks their industry, and sees a per-ratio verdict
   (above / below / in range) plus a one-sentence headline. Pure
   client-side computation; nothing stored. Header nav now carries
   a "Check" link.

7. **Methodology surface.** New page at
   `/methodology/key-benchmarks` explaining the framework in plain
   operator language. Linked from the cost-stack pages.

## Quality gates added (4)

| Gate | Enforces |
|---|---|
| `verify_cost_share_invariant` | Per-sector cost shares sum to ~1 with margin within hard cap |
| `verify_key_benchmark_assignment` | Every sector has a valid key benchmark + rationale; underlying share is non-trivial; canonical mapping agrees with cost profile inline value |
| `verify_comparative_voice` | No sentence-initial descriptive openers ("Typical operators...") in user-visible source. Warn-only initially; flip to strict via `COMPARATIVE_VOICE_STRICT=1` |
| `verify_turnover_bands` | Per-sector bands present; thresholds positive, monotonic, contiguous; large.max_usd is null; referenced sectors exist in the cost profile |

Total prebuild chain: **18 gates, all passing**.

## What deliberately remains for later

- **Phase 6b: per-industry turnover-band overrides.** The 6 sentinel
  sectors cover the obvious cases; the remaining 19 fall back to the
  default thresholds. Founder hand-correction welcome.
- **/check email-gated PDF.** The plan reserved this; verdict text
  stays free, the takeaway PDF is the gate. Not yet built.
- **Per-cell narrative regeneration.** The cached
  `cell_narratives_v1.json` retains its current voice; the new
  comparative-voice generator is exposed via the API and used on the
  KeyBenchmarkBanner, but the bulk narrative cache has not been
  re-rendered through the new voice.
- **Hard-fail on `verify_comparative_voice`.** Currently warn-only.
  Flip once any remaining cached strings are migrated.

## How to extend

**Add a new sub-industry.** Append to
`src/lib/taxonomy/industries.json`. Set `parent_id` to the closest
measured industry so inheritance covers data gaps. Run the prebuild
gate.

**Override the key benchmark for an industry-level entry.** The
current model picks per-sector. To override at industry level, extend
`key_benchmark_assignments_v1.json` with an `assignments_by_industry`
block and teach `getKeyBenchmarkForIndustry()` to check it first.

**Add a sector to turnover_bands_v1.json.** Three contiguous bands
(small + medium + large) in USD, large.max_usd = null. The gate
enforces the structure.

**Add an industry to the `/check` picker.** Append to the `PICKER`
array in `src/app/check/CheckForm.tsx`. The verdict engine resolves
any taxonomy industry id automatically.
