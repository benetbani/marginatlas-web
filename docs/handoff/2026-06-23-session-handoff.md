## 4. The approved visual language (hard-won over many iterations)
The founder rejected several attempts before this locked. Internalise it before building UI; deviating wastes his time.

- **Palette: STRICT. Terracotta + neutral GRAYS only. NO green (no moss), NO brown shades.** In any value/cost chart: kept/positive = TERRACOTTA, costs/the-rest = GRAY. (This is a HARD rule, recorded in §16 and in memory; it was violated twice and rejected both times.)
- **Fonts:** Fraunces (display serif, titles + hero figures) + Geist (body). Tabular numbers everywhere.
- **Surfaces:** white hairline cards (1px `#e4e2dd`), 14px radius, a subtle warm shadow. Warm-white page ground `#fbfaf7`. Restrained terracotta accent doing real work, never a flooded tinted box.
- **Read pattern:** the answer/visual comes FIRST. NO per-item generated sentences (thousands of bland sentences are not worth it). The design must let the operator SEE the situation, not decode raw numbers.
- **Comparative, vs the NATIONAL average, not the world** (kills the "Switzerland always high, India always low" distortion). Metric rows are **diverging bars from a zero centre** (= national average): terracotta to the right is above, dark gray to the left is below, with the percentage-point difference as the number.
- **Icons:** real inline SVG, one consistent family (storefront = rent, people = footfall, map-pins = competition, coin = spend). No emoji.
- **Proportions = a hover-reactive DONUT** (gray slices + terracotta for the dominant group). **Comparisons = bars** (never dot-plots; the founder rejected dots).
- **No population counts** anywhere (a small-resident area can pull huge footfall).
- **Honest not-held states** on every component ("not held here yet").
- **The impeccable ban list** (enforced): no side-stripe coloured borders, no gradient text, no decorative glassmorphism, no hero-metric cliche, no identical card grids, no `#000`/`#fff`, no em-dashes.

## 7. Problems, gotchas, hard-won lessons
- **Colour (twice burned):** never use green or brown. Terracotta + gray only. See section 4.
- **Verdict sentences do not scale:** do not generate a per-place prose sentence per section. Use visual + number.
- **Compare vs national, not world.** Absolute global numbers distort by country.
- **Windows prebuild flakiness:** `npm run prebuild` (parallel, concurrency 4) intermittently dies with `spawn UNKNOWN` / esbuild "service was stopped" mid-run. Use **`npm run prebuild:serial`** for a clean read. Verified clean = "Hard fails: 0".
- **Bash CWD resets** to `E:\atlas` each call; prefix `cd /e/atlas/website && …`.
- **Never open a dev server / browser to show the founder.** Deliver standalone HTML he opens himself (the Launch preview panel surfaces them automatically on write).
- **Verify cadence (founder-approved):** `npx tsc --noEmit` + `npm run prebuild:serial` before any delivery. Full `npm run build` and deploys need explicit permission.
- **Interview dedup:** the parallel-cluster brainstorms produce 30 to 45 percent duplicate questions across angles. Dedup to the distinct decisions before serving, and tell him you did (he hates redundancy).
- **Infra:** Claude home is junctioned to `E:\Others\.claude` (canonical). If history/plugins vanish, see the `env-claude-home-location` memory.
