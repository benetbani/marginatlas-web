Some statistical agencies publish beautiful, accessible data (US Census, Eurostat). Others… don't.

**Brazil's IBGE** has the data but it's organized by survey rather than by industry, requiring cross-joins of CEMPRE, PAS, PMS, and POF. We got 25,000 cells out, but the granularity is rough.

**India's MoSPI** has rich Annual Survey of Industries data, but the API requires registration through an Aadhaar-gated portal that often doesn't work for non-residents.

**Mexico's INEGI** publishes via a token API where the registration form is buried and 404s.

**Nigeria's NBS** publishes mostly as PDFs.

For these countries we currently show OECD QNA + World Bank macro context. Per-firm SMB data is a v2 goal.
